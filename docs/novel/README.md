# Novel

Fiction layer: a ~100-page puzzle-driven thriller set in the FringeIsland
universe, told through the eyes of a newcomer FIM. Dan Brown-style
structure (prologue + 36 short cliffhanger chapters + epilogue);
atmosphere informed by Simon Stålenhag and Mats Åkerman (inspiration,
not depiction).

**Canon note:** the novel is canon-conformant on universe mechanics but is
NOT a canon source. On conflict, universe-discovery Session 01 wins and
the novel is corrected forward.
