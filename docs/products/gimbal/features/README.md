# Features — The Gimbal

Feature specifications for The Gimbal, the senses surface of the one experience (ADR-U025; native iOS and Android are its shipping targets). Each feature uses the Shape Up pitch format with BDD stories embedded as Given/When/Then acceptance criteria. `G` covers shell features only (navigation, rendering, packaging); experience features belong to their owning capabilities and declare `requires-equipment:`.

**Feature ID prefix:** `G` (e.g., `FEAT-G001-ar-overlay.md`)
**Template:** `../../../templates/feature-spec.md`
