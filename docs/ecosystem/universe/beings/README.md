# Beings — Entities That Inhabit the World

**Purpose:** The entities that exist within the FringeIsland universe — the Whisp, NPCs, and the creative roles that shape the world from within.

---

## Overview

FringeIsland is inhabited. Not just by members, but by entities that carry meaning — the Whisp as personal instrument, NPCs as narrative presence, and Dreamineers as the living creative force that keeps the world evolving.

This directory describes these beings as universe concepts — what they are, how they behave, what they mean. Technical implementation lives in platform service specs.
