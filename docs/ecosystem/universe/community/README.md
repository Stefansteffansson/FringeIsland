# Community — Dynamics and Founding Moments

**Purpose:** How community works within the FringeIsland universe — roles in practice, the founding moment, and the dynamics that make the ecosystem alive.

---

## Overview

FringeIsland is a movement, not a product. The community is not an add-on to the platform — it is the reason the platform exists. This directory describes the community as a living organism: how it begins, how it grows, and how its founding moments shape everything that follows.
