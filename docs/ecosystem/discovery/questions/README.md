# Questions

Ecosystem-level open questions, one per file.

- **ID / file:** `cq:NNN` in `CQ-NNN.md` (for example `cq:010` in `CQ-010.md`).
- **Status:** `open`, `parked` or `resolved`, in frontmatter.
- **Write policy:** `editable`; the app rewrites the whole file.
- **Generated view:** `QUESTIONS-VIEW.md`, grouped by status with the quick-index table; rebuilt by the sweep, never edited by hand.
- **Import source:** the `### CQ-NNN: Title` sections of `../../thinking/OPEN_QUESTIONS.md`, through the importer's question preset. The original is never modified by the importer.
