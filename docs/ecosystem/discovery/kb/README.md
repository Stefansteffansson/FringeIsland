# Knowledge base

The Whisp and universe foundations knowledge base as entity files.

- **Numbered entries:** `kb:N` in `KB-NNN.md` (for example `kb:14` in `KB-014.md`), from the KB's `### N. Name — Title` entries.
- **Non-numbered sections:** `kbx:<slug>` in `X-<slug>.md` (for example `X-mirror-questions.md`), for the principles, the synthesis insights and the cosmology-of-embodiment sections.
- **Write policy:** `editable`; the app rewrites the whole file. A `cites:` field names the statements an entry is derived from and yields `derived-from` edges.
- **Generated view:** `KB-VIEW.md`, entries in numeric order followed by the non-numbered sections; rebuilt by the sweep, never edited by hand.
- **Import source:** `../../thinking/2026-06-15_knowledge-base_whisp-and-universe-foundations.md`, through the importer's KB preset. The original is never modified by the importer.
