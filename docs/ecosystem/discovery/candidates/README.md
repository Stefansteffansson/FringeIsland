# Candidates

Unlocked candidate material (the lettered Sections A-H and their successors), one section per file, one subfolder per source document.

- **ID / file:** `cand:<source-slug>/<letter>` in `<source-slug>/<letter>.md` (for example `cand:gimbal-origin/B` in `gimbal-origin/B.md`).
- **Status:** `candidate` on import; a note promoted from the canvas also lands here as a candidate.
- **Write policy:** `editable`; the app rewrites the whole file.
- **Import source:** the candidate files' `## X. Title` sections, one subfolder per source file. The originals under `../../thinking/` are never modified by the importer.

Spec: [`../../thinking/2026-09-11_discovery-canvas-spec.md`](../../thinking/2026-09-11_discovery-canvas-spec.md), section 5.
