# Session notes

Material from the discovery log that is not a locked statement: the opening frame, resume headers, the questions register, and text before the first statement of an import that Stefan chose to keep.

- **ID / file:** `log:<slug>` in `<slug>.md` (for example `log:opening-frame` in `opening-frame.md`); `session:` names the session the note belongs to.
- **Write policy:** `editable`; the app rewrites the whole file.
- **Generated view:** none of its own; the sweep may place notes in `../statements/SESSION-VIEW.md` by session.
- **Import source:** the importer's "text before the first match" choice, or a whole-file import of a log fragment. The original is never modified by the importer.
