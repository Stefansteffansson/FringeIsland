## Key Decisions Locked (quick reference)

| Decision | Summary |
|----------|---------|
| Layered anatomy | Primary architectural framework — dependency order made explicit |
| Five verticals | Admin, Privacy, Notifications, Observability, Transactions |
| Visitor anonymous sign-in | Supabase anon session → temporary profile → converts on registration |
| profile_data table | Separate flexible table — buckets are data not schema |
| API-first | Database → /api/route → component. Never skip the middle step. |
| Privacy as dedicated vertical | Founding value — not absorbed into Administration |
| Stripe Connect | Never build payment logic. FringeIsland stores only reference + entitlement. |
| Feature flags in L0 | Database table — toggleable without redeploy |
| API versioning from day one | /api/v1/ prefix — costs nothing now, expensive to retrofit later |
| i18n + a11y as constraints | Not features — built correctly from day one |
| Cascade before implementation | Every lifecycle event needs full cascade spec before code |
| Forum anonymisation | Soft-flag display — historical data never mutated |
| Baseline is Claude Code generated | Never hand-written — regenerated after each significant session |
