## Non-obvious insights

- **A bible that condenses is a bible that loses.** The Phase 4 writing compressed material Stefan had already kept ("definite keep" on Candidate B-F), and no check caught it because the doc-health forward check only looks at "Baked into the bible" lists, not at candidates ruled earlier. The audit found ten more small losses across five chapters. The next Phase 4-style writing pass should carry a "kept but compressed" check.
- **The auditors' line numbers drifted; their words did not.** Three of the fifteen sources sat one line off the numbers reported, because the auditors read a file that had since gained lines. Verifying by the quoted words, not the line, found every one.
- **A chapter-heading anchor is app-specific; a file link is not.** Obsidian and GitHub write heading links differently, so a link that jumps into a session would have worked in one reader and not the other. The reading model made the question moot.
