# Planning

How work flows from idea to shipped code. The single canonical process lives in `PROCESS.md`.

## Layout
- `PROCESS.md` — way of working (read this first)
- `DEFERRED_DECISIONS.md` — parked decisions to revisit later
- `backlog/` — work items at maturity 0–4
- `cycles/` — active cycle and historical retrospectives
- `prds/` — Product Requirement Documents (one per major feature)
- `sessions/` — Claude session bridges
