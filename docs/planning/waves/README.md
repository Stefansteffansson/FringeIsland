# Waves — Strategic Focus Periods

Waves are **thematic focus buckets** that define what the ecosystem prioritises during a period. They are **NOT sequential gates** — work from any wave can be in any maturity state at any time. Waves overlap naturally; the wave label says what the ecosystem is *focused on*, not what is *forbidden*.

Each wave file defines: thematic focus, features in scope (linking to feature specs in the ecosystem tree), and wave-level Definition of Done. Wave files **reference** features — they don't contain them.
