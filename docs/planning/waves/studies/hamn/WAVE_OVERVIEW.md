## Mission

Transform the platform's visual and experiential quality by introducing
a complete design system and accessibility framework, then applying both
through a full UX/UI redesign. Hamn is where FringeIsland stops looking
like a platform under construction and starts feeling like the experience
it is meant to be.

---

## Wave Is Done When

- [ ] The FringeIsland design system is complete and documented
- [ ] The accessibility system is defined and implemented
- [ ] The full web app has been redesigned according to both systems
- [ ] All existing UI from Ferd and Eid is conformant with the new design and accessibility standards
- [ ] All open questions for this wave are closed
