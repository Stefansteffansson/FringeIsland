## What Is This

A complete, documented design system that defines the visual language,
component library and interaction patterns of the FringeIsland experience.
It is the single source of truth for how FringeIsland looks and feels.

---

## Why We Are Building This

Without a design system, every new UI surface is a creative decision from scratch.
A design system creates consistency, speed and quality — and makes it possible
for Dreamineers and contributors to build new experiences that feel native to FringeIsland.

---

## How It Is Supposed to Work

- A complete token set: colour, typography, spacing, elevation, motion, iconography
- A full component library: all UI building blocks used across the platform
- Usage guidelines: when and how to use each component
- The design system builds on and replaces the minimal foundation from Eid
- It is living documentation — maintained and evolved as the platform grows
