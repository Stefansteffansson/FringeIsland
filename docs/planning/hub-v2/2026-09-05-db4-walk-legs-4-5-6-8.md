## Leg 4 — the bulk bar: one reason, per-member outcomes (FEAT-H039 + H049 STORY-1)

**Actors:** walk-admin in A; Mona in B.
**Consequences before the click:** a bulk suspend writes `users.suspension_reason` and an audit row **per member**, fans out an `account_suspended` notice to each, and force-ends their sessions (Mona's B window will hit the suspended-account surface on its next request). 1. **A:** sign in as walk-admin → `/admin/members`. In the search box type `walk-` → the list shows **exactly the six** `walk-*` rows (server search; the As-of line and the pager render). If it shows more or fewer, stop: the population is wrong (P4).
2. **A:** tick **Select Mona** and **Select Kalle** (never Select page here — page-scoped selection on a six-row page would include yourself) → the bar reads **2 selected**. The bar's three actions: **Suspend** / **Reactivate** / **Force sign-out**. Reactivate is disabled (no selected member could take it — both are active).
3. **A:** **Suspend** → the modal titled **Bulk suspend** opens with ONE reason field labelled *Shown to the member*; **Confirm is disabled until the reason is non-blank** (that is the leg's first proof — a blank reason cannot be sent). Type `Walk leg 4 — a bulk hold, one reason for both.` → Confirm.
4. **A, expected:** per-row outcomes render for Mona and Kalle — 2 succeeded, none refused; both rows now read **Suspended**; the selection clears. Re-open Mona's detail (`/admin/members/<Mona>`) → the state-honest rail shows Suspended. *(Script correction, first runner pass 2026-09-06: the rail shows the state, not the reason — FEAT-H049's privacy line renders the reason only where the platform delivers it, the member's own account read and the notification rows; the reason is proved in steps 5 and 7.)*
5. **B:** Mona was signed in (`/groups`) — click anything → the suspended-account surface renders, with **"The reason given: Walk leg 4 — a bulk hold, one reason for both."** above the sign-out exit (H049 STORY-3). No hard reload needed (the in-session wall, FEAT-H038).
6. **A:** search `walk-` again, tick Mona and Kalle → **2 selected** → **Suspend** is now disabled (neither could take it); **Reactivate** is enabled → **Bulk reactivate** modal, the same reason field, Confirm disabled until non-blank → `Walk leg 4 — reinstated.` → Confirm → per-row outcomes 2 succeeded; rows read **Active**.
7. **B:** Mona signs in again → `/notifications`: two plain notices in the bell — the kind labels as titles (*account suspended* / *account reinstated*), the two reasons as bodies, **no action affordance**, the *Holds & sanctions* icon (H049 STORY-4).

## Running the legs with the walk runner (added 2026-09-06)

The four legs are codified as **walk specs** — `hub/tests/walks/leg-{4,5,6,8}-*.walk.ts` on `hub/playwright.walks.config.ts` — one test per numbered step, the script's "expected" lines as assertions, a screenshot per step attached to the HTML report, a trace per test. Actors sign in on their own browser contexts, so a leg holds two or three cast members at once (leg 4: the admin acts while Mona's window is live; leg 8: Astrid, Wanda and the admin in turn). A walk spec never sweeps: the cast is torn down by `walk:cast teardown`, after.

```bash
# from hub/ — the dev server may already be running (reused); the cast exists (P2/P3)
echo 'WALK_PASSWORD=<the cast password>' > .env.walk.local     # gitignored; never in the repo, never on a command line
npm run walk:run:headed -- leg-5          # one leg, watch the windows
npm run walk:run                          # all four, headless
npm run walk:report                       # the HTML report: every step's screenshot
```

Re-runs on the same cast are supported: leg 4 settles an interrupted pair before it starts and stamps its reasons per run; leg 8 uses the cast's Drift and **skips, saying so, once Drift is closed** (re-create the cast). **First runner pass, 2026-09-06, all four green** — leg 4 10/10, leg 5 4/4, leg 6 6/6, leg 8 7/7 — with one script correction (leg 4 step 4, above) and no product finding. The felt items (copy, timing, the empty states) stay the walker's: the runner's screenshots are what to read for them.
