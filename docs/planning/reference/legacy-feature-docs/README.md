# Legacy feature docs (pre-Model-A Ferd)

**Status:** Historical reference snapshot. Read-only; never updated.
**Provenance:** The pre-Model-A Ferd feature documents (10x FR-, 5x AR-, 1x NF- plus INDEX and
one archived review), rescued from `docs/old_products/ferd/development/` before that tree was
deleted (April 2026), parked in `docs/TMP/OLDFEAT/` since, and given this permanent home on
2026-06-10 (TASK-DOC-001; first time under version control).

**Why kept:** These are the densest surviving record of what Ferd actually implemented and why —
`docs/planning/reference/ADMIN-DEUSEX-GAP-ANALYSIS.md` and the 2026-04-28 capabilities synthesis
cite them as sources. The Model A feature specs under the ecosystem tree supersede them as
*specifications*; these survive as *evidence*.

**Read-through caveat:** they predate the reconciliation (Session B, 2026-06-10). "Visitor" reads
as Shadow, the group-role "Member" as Participant, and any cosmology as superseded — see
`docs/ecosystem/universe/roles/README.md` and `docs/ecosystem/universe/cosmology/README.md`.
References to `docs/old_products/...` paths inside are era-correct; those trees no longer exist.
