### Learned

- **A per-function REVOKE discipline cannot survive `pg_default_acl` — the documented pattern was wrong at the layer, not merely unapplied.** Supabase default privileges re-grant EXECUTE to `anon`/PUBLIC on every new public function, so every Groups contract (PC010–PC015) was *born re-opened* no matter how faithfully the repo's `REVOKE FROM PUBLIC` pattern was followed on the functions it knew about. This is why the grant gap recurred across six consecutive cycles of disciplined work: an instance-level rule was fighting a class-level default and silently losing every time. It accumulated to **77 anon-executable SECURITY DEFINER functions**, including `_erase_mist(uuid)` — unauthenticated arbitrary-account erasure via PostgREST with the public anon key. Fixed at the class: `ALTER DEFAULT PRIVILEGES` + full sweep + the two internal primitives closed to `authenticated`; verified live 77 → 0 (PR #105, migration `20260706201500`, applied to production under the schema gate).
- **The deferred "grant sweep" was mis-filed as inventory work.** It sat on the parked list as "twelve documented sweep items, mechanism known" — a to-do framing for what was actually a growing production vulnerability class (every new migration added exposure). The fingerprint to recognize next time: a manual sweep list that *grows back* after being worked is a wrong-layer pattern, not an unfinished chore. It escalates to a structural fix; it does not re-park.
- **Route policy that lives only in ADR prose drifts within one cycle.** All five conformance deviations (three `getClaims`-on-mutation routes, two mutation-only routes on Edge runtime) came from the most recent cycles — mostly G-F/FEAT-H018 — written *while* the same cycles were faithfully executing the DoD rows that exist (adversarial direct-`rpc()` tests, six for six). What the DoD checklist names survives; what only an ADR states drifts. ADR-U036/U037 had no build-time enforcement, so the drift was invisible until an on-demand audit that only ran because a perf complaint widened.
- **Client-rendered pages with per-component fetches are a first-load anti-pattern.** `/groups` paid document → bundle → hydrate → `getSession` before requesting the first data byte, across five separate first-paint BFF calls, with `/api/groups` fetched ×3 (effect keyed on the `user` object reference, which the auth listener re-emits per hydration event). ADR-U042 is the counter-pattern: the first-paint bootstrap read is a **BFF bundle** (`GET /api/me/overview`, parallel fan-out, per-slice envelopes, bundle-only), fired once per session, with SWR session caches behind it. Notably, the prior art (profile session cache, once-per-session `AccountStateProvider`) already existed in-repo and was **not adopted** when the Groups pages were built — prior-art adoption needs a checklist row, not memory.
- **Cold ≠ boot.** The corollary the perf session added to measure-the-real-path: the 401 probe isolates function boot, and boot was innocent; only the authenticated waterfall shows the composite (connection setup, contention, auth exchange). Both measurements were needed to place the cost correctly.
- **Carried-forward greens must be re-read when an ADR lands.** A PC014 test asserted the pre-ADR-U041 canon (any-active-member nominee) and stayed green until re-read against the new canon (amended same-day with a Post-6-done note). A passing suite encodes yesterday's rules.
- **A surface derivation with no substrate home is a latent fork.** `hub/lib/groups/leadership.ts` derives "which nominations are pending" in client TypeScript — including client-clock date-math on `expires_at` — as the only Groups read outside the RPC-contract pattern. Not a security hole (RLS scopes the rows; the respond RPC gates expiry authoritatively), but the derivation is sole-homed in Hub code: a sibling surface (the Gimbal) would have to re-implement it, possibly differently. The L3 question "which contract is this derivation's home?" belongs at decomposition, where it costs one line, not at audit, where it costs a finding.

## 4. Process changes

- **Grant discipline moves from pattern to gate.** (a) The class fix is in (`ALTER DEFAULT PRIVILEGES`, migration `20260706201500`). (b) `hub/tests/integration/platform/anon-execute-lockdown.test.ts` is the standing guard — a red there is a critical gate-stopper, and the test extends if new roles or schemas appear. (c) Schema-gate checklist line: a PR introducing a SECURITY DEFINER function shows that regression test green; manual `REVOKE` diligence is no longer accepted as evidence. (d) Meta-rule (PROCESS.md-worthy, `type:process`): **a manual sweep item that grows back after being worked is a wrong-layer pattern — its second recurrence mandates a structural-fix proposal, not a re-park.**
- **Route-policy conformance becomes a build-time check.** Author a conformance test that walks `hub/app/api` route modules and asserts the ADR-U036/U037 matrix — mutating verbs → `getUser()` + Node runtime; hot-path reads → `getClaims()` + Edge + `dub1` — against an explicit documented-exception list. Wire it into the surface-half DoD exactly the way the GP2 adversarial-`rpc()` rows were wired in after the API-boundary retro (that mechanism demonstrably works — those rows held six for six while the un-rowed policy drifted). Until the test exists, the `feature-development` skill's surface-half checklist carries the two rows verbatim.
- **First-paint data-boot row in the surface-half DoD.** A new page that gates first paint on fetches must name its boot path — overview-bundle slice, session cache, or a justified standalone read — per ADR-U042's guardrails, and state its cold-visit budget. In-repo prior art is a checklist item, not memory.
- **Sole-home question at decomposition.** The `ecosystem-decomposition` L3 pass asks, for every list or derivation a surface renders: *which substrate contract is its home?* A derivation homed only in one surface's TypeScript (the `leadership.ts` case) is a spec finding at decomposition, not an audit finding after close.
- **Keep (confirmed, not new):** substrate-audit-at-decomposition (twice corrected a cycle premise), the design-gate-then-build shape for governance-touching cycles (G-F), and the post-`6-done` manual live walk — worth promoting to an explicit per-area gate row ahead of the retro.
