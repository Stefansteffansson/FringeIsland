# Backlog

Work items moving through the maturity pipeline (see [`../PROCESS.md`](../PROCESS.md) Section 1).

## Structure

- [`tasks/`](./tasks/) — ephemeral task files (`TASK-{NNN}.md`). Tasks are created only for features at maturity `4-ready` or higher, and **deleted after the cycle retrospective is committed**. The retro itself is the permanent learning artifact.

Items at lower maturity (`0-raw` through `3-specified`) live in the ecosystem tree as feature specs under each owner — they are not duplicated here. The backlog tracks **work in motion**, not the catalogue of what exists.

Every backlog item is tagged: product / type / maturity / domain service (and optionally wave). See `../PROCESS.md` §7 for the tagging system.
