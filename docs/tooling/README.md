# Tooling

Docs in this folder describe how the development environment is configured for working on FringeIsland — MCP server setup, shell command policies, editor config, and anything else that describes how the machine is wired rather than what the product does or how the team works together.

## Contents

- [`SUPER_SHELL.md`](./SUPER_SHELL.md) — Super Shell MCP operational contract: whitelist tiers, known gotchas, PATH requirements.

## What belongs here

- MCP server configuration and operational notes
- Shell, terminal, and command execution policies
- Local development environment setup (Node versions, package managers, etc.)
- Editor and IDE configuration shared across the project
- Claude Code / Claude Desktop setup notes specific to this repo

## What doesn't belong here

- **Architecture** — goes in `ARCHITECTURE_ANATOMY.md` or an architecture folder
- **Team practices and ways of working** — goes in `docs/ecosystem/how-we-work/`
- **Session notes, plans, waves** — goes in `docs/planning/`
- **Feature specs** — goes wherever feature specs live in this repo
