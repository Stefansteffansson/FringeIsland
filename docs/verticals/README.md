# Cross-Cutting Verticals

Concerns that touch every layer (Platform Core, Domain Services, Products, Studios). Each vertical has its own spec following `../templates/vertical-spec.md`.

**Feature ID prefix:** `V`

**Every feature spec must address all five verticals** in its Vertical Impact section — no vertical left blank. If a vertical does not apply, mark it explicitly as "None" with a one-line reason.

## The five verticals

- `administration.md` — V1 Administration & Moderation
- `privacy.md` — V2 Privacy, GDPR, AI Consent
- `notifications.md` — V3 Notifications
- `observability.md` — V4 Observability, Audit, Errors
- `transactions.md` — V5 Transactions, Stripe
