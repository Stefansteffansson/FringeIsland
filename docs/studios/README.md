# Studios

Authoring tools used by Dreamineers and Weavers to create FringeIsland content. Each Studio writes to a specific Domain Service.

| Studio | Writes to |
|---|---|
| Universe Studio | World Model (DS-1) |
| Arc Studio | Narrative Engine (DS-2) |
| Journey Studio | Experience Engine (DS-3) |

## Per-studio files
- `DESCRIPTION.md` — template `../templates/studio-description.md`
