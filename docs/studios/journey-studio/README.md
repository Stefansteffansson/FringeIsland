# Journey Studio

The full Dreamineer lifecycle for journeys: **design, deploy, manage, retire**. Dreamineers use Journey Studio to craft step-by-step learning experiences and to manage published journeys over time.

**Feature ID prefix:** `JS`
**Writes to:** Experience Engine (DS-3) — Journey Studio is the authoring + management surface; Experience Engine is the runtime that delivers journeys to FIMs.

## Structure

- `features/` — Feature specifications using `FEAT-JS*` IDs (Shape Up pitch + BDD stories)
- `DESCRIPTION.md` — Studio identity _(to be written using `../../templates/studio-description.md`)_
- `SPECIFICATION.md` — Build spec _(to be written)_
