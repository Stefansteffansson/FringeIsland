# Universe Studio

The full lifecycle environment for **world / universe content**: design, deploy, manage, retire. Universe Studio is where Dreamineers shape the Three Worlds, the Whisp, lore, and the foundational structure that journeys and arcs live within.

**Feature ID prefix:** `US`
**Writes to:** World Model (DS-1) — narrative arcs are owned by Arc Studio (writing to Narrative Engine), not Universe Studio.

## Structure

- `features/` — Feature specifications using `FEAT-US*` IDs (Shape Up pitch + BDD stories)
- `DESCRIPTION.md` — Studio identity _(to be written using `../../templates/studio-description.md`)_
- `SPECIFICATION.md` — Build spec _(to be written)_
