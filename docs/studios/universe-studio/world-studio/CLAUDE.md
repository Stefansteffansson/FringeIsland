# CLAUDE.md — World Studio (entity)

Load order: root `CLAUDE.md` -> `docs/studios/CLAUDE.md` -> `docs/studios/universe-studio/CLAUDE.md` -> this file -> `README.md` here.

Entity-specific rules:

- **Two faces, one entity.** Creator (hard/physical) and Anthropologist (soft/cultural) are both
  World Studio. Do not split them into separate entities or studios; do not assign the
  Anthropologist anywhere else.
- **Scope is the gate.** Personal-scope features (own-home furnishing) must never require
  Dreamineer authority; shared-scope features must always require it. Never gate by anything
  other than scope + role permission.
- **Equipment split.** Capture features key to `sensors`; deep-edit features key to
  `comfortable-canvas`. Every WS feature spec carries `requires-equipment:`.
- **NPC seam.** World Studio authors NPC body + culture layers only. The character layer belongs
  to Arc Studio — if a feature wants to author names/wounds/arcs, it is in the wrong studio.
- **Writes to DS-1 World Model.** Do not write world-state through any other domain service.
- Feature-ID prefix: **WS**.
